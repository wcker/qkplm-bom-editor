01 / COMPONENT FACADE

创建受控编辑器

使用纯前端 Props/Outputs 门面挂载编辑器，宿主只负责提供文档、列定义和输出回调。

可运行
输入BomSchema + Snapshot + 列定义

Schema、文档和列定义共同构成受控初始化输入，交互结果通过 outputs 输出。

过程规范化 → 挂载 → ready

组件先验证 Snapshot，再同步 Canvas、语义 DOM 和编辑 Portal。

结果ready / selectionChanged

宿主接收值无关的状态事件，不需要依赖 renderer 内部对象。

当前输入生成的场景结果component-output
点击“运行示例”查看输出
TypeScript
import { createBomEditorComponent } from '@qkplm/bom-editor';

const component = createBomEditorComponent({
  schema,
  document: snapshot,
  columns,
  initialView: {
    rowHeight: 30,
    columns: [
      { columnId: 'materialCode', width: 140, frozen: 'start', visible: true },
      { columnId: 'quantity', width: 116, frozen: false, visible: true },
    ],
    expandedIds: ['occ-0001'],
    selection: {
      activeCell: { occurrenceId: 'occ-0001', columnId: 'materialCode' },
      range: null,
    },
    scrollLeft: 0,
    scrollTop: 0,
  },
  editNavigation: { enter: 'down', tab: 'next-editable' },
  outputs: {
    onDocumentChange: ({ snapshot, commit }) => save(snapshot, commit),
    onSelectionChange: (event) => announce(event.selection),
    onViewChange: (event) => persistView(event.view),
    onError: (event) => report(event.error.code),
  },
});

component.mount(document.querySelector('#editor')!);

02 / TRANSACTION

提交字段编辑

用公开命令修改字段，得到单一原子 Commit，并可通过 Undo 恢复规范 Snapshot。

可运行
命令setField

通过 occurrenceId 和 Schema fieldPath 定位字段，禁止直接写对象属性。

事务FIFO + 原子提交

beforeTransaction、Schema 和 revision 校验全部通过后才发布。

历史Undo / Redo

Commit 保留前后选区和规范哈希，撤销不会产生半提交。

当前输入生成的场景结果transactionCommitted
点击“运行示例”查看输出
TypeScript
const result = await editor.execute(
  {
    type: 'setField',
    occurrenceId: 'occ-0007',
    fieldPath: 'specification.quantity',
    value: 24,
  },
  { origin: 'demo:quantity-edit' },
);

if (result.ok) {
  console.log(result.value.commit.transactionId);
  await editor.undo({ origin: 'demo:undo' });
}

03 / CONTROLLED VIEW

控制列视图

列宽、自动适应、顺序、显隐和冻结属于受控视图状态，通过 viewChanged 输出，不修改 BOM 文档。

可运行
调整width / auto-size / order

拖动或双击列边界，或使用列头菜单自动适应；宿主收到稳定列 ID 和新几何。

冻结start / end / false

冻结列不会改变数据顺序，滚动时保持固定坐标。

历史交互 Undo / Redo

视图变化进入交互历史，领域 Snapshot revision 保持不变。

当前输入生成的场景结果viewChanged
点击“运行示例”查看输出
TypeScript
const nextColumns = columns.map((column) =>
  column.columnId === 'quantity'
    ? { ...column, width: 128, frozen: 'start' }
    : column,
);

const result = editor.setColumns(nextColumns);
if (!result.ok) report(result.error);
// outputs.viewChanged 会携带稳定列 ID 和 viewRevision。

04 / QUERY & FORMAT

查找与格式化

查找请求只返回稳定地址和计数；列显示格式只影响展示，不改变规范值。

可运行
模式prefix / exact / fuzzy / regex

正则输入会先编译校验，非法表达式不会改变当前文档。

结果count + addresses

结果只携带 occurrenceId、columnId 和 rowIndex，不泄露字段原文。

格式Intl 展示层

百分比、货币和日期格式在 view 层渲染，规范值保持稳定。

当前输入生成的场景结果queryResult
点击“运行示例”查看输出
TypeScript
const result = await editor.search({
  query: 'PUMP-',
  mode: 'prefix',
  caseSensitive: false,
});

editor.setColumns(columns.map((column) =>
  column.columnId === 'price'
    ? { ...column, format: { kind: 'currency', currency: 'CNY' } }
    : column,
));

05 / CLIPBOARD POLICY

安全复制粘贴

剪贴板经过声明式 Policy 和格式限额检查，成功后才进入单一可撤销事务。

可运行
来源internal / html / text

可输入三种候选表示；失效的高优先级候选会继续安全降级。

诊断candidateFormat

全部候选失败时，输出按来源格式汇总的无值定位诊断。

提交one paste transaction

解析、目标复核和 Schema 转换完成后一次性提交，失败保持 Snapshot 不变。

当前输入生成的场景结果pasteOperation
