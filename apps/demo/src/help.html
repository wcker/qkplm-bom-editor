01

快速开始

先从独立示例确认 Props/Outputs，再打开完整 10K 工作台。

  1. 打开工作台访问 /，等待状态栏变为“10K 文档已就绪”。
  2. 选择目标单元格单击任意可编辑格，列设置、输入和右键菜单会绑定到当前地址。
  3. 验证输出编辑、列操作和粘贴完成后，观察状态栏以及宿主收到的事件。
页面职责工作台用于真实鼠标键盘操作；示例中心用于查看协议输入输出；验收页 /acceptance.html 只用于自动化测量，不是日常操作入口。
02

编辑与提交

编辑器先保留草稿，只有提交校验通过后才产生文档事务。

鼠标与键盘

  • 双击单元格或按 Enter/F2 进入编辑。
  • 输入期间由 DOM Portal 承载草稿，Enter 提交，Esc 取消。
  • 提交后默认移动到同列下一可见可编辑单元格。

失败语义

  • 只读列、Schema 不合法或 revision 过期时不会产生部分修改。
  • 错误会通过状态栏和错误输出报告，原 Snapshot 保持不变。
  • 远程 DataSource 不属于纯前端组件门面，需由宿主自行协调。
03

选区与填充柄

矩形选区、轴选区和右下角填充柄分别对应不同的操作边界。

选区

  • 拖动单元格可创建矩形选区，按 Shift 扩展端点。
  • 点击行号选择整行，点击列头选择整列；Ctrl/Cmd 可追加范围。
  • 多范围复制保持安全拒绝；删除、粘贴和复制式填充会在各自的原子边界内处理。

填充柄

  • 拖动右下角小方块向下复制；合格的多范围会保留同伴范围。
  • 按住 Alt 开始单矩形拖拽，按前两行数值或 ISO 时间继续序列。
  • 拖到视口底部会自动滚动；移出虚拟行窗口后仍会继续预览。
  • 释放、取消、丢失指针捕获或销毁组件时，预览会停止并清理。
04

行列与冻结

列操作集中在列头右键菜单，行操作集中在行号右键菜单。

入口可用操作历史
列头右键左/右插入、删除、隐藏、显示全部、冻结到左侧/右侧、取消冻结、排序、筛选、格式、按内容自动调整列宽、恢复默认列宽和复制交互 Undo/Redo
行号右键 / 拖动插入同级/子级、删除、上移/下移、增加/减少缩进、全部展开/折叠、设置行高、按换行自动调整、恢复默认行高、清除内容；拖动到上下边缘会自动滚动，释放后才移动节点行高为交互历史；结构为文档事务
列边界鼠标拖动调整宽度；双击边界按当前渲染窗口自动适应；聚焦后使用 Ctrl/Cmd + Alt + 左/右交互 Undo/Redo
列设置入口先选中列内单元格，再点击工作台顶部“列设置”，或从列头右键菜单进入。可修改显示名称和属性名称；属性名称必须是 Schema 的 fieldName，应用时会同步解析为实际 fieldPath。显示格式只改变 view，不改变原始规范值。
05

查找与显示格式

查找面板支持导航和计数，显示格式使用明确的列配置。

查找

  • Ctrl/Cmd + F 打开查找面板。
  • 支持前缀、精确、模糊和正则模式，可区分大小写、匹配整个单元格。
  • 按 Enter/Shift + Enter 定位下一项/上一项，计数显示为“当前 / 总数”。

格式

  • 文本、整数、小数、百分比、货币、会计、科学计数、分数、日期和日期时间均由列设置选择。
  • 小数位、千分位、货币代码、日期样式、对齐和自动换行均可单独配置。
  • 非法格式配置会被拒绝，当前列保持原设置。
06

复制、剪切与粘贴

剪贴板操作采用浏览器受信事件和安全 Policy，避免误改数据。

复制与剪切

  • Ctrl/Cmd + C 复制当前选区；支持纯文本和受限 internal envelope。
  • Ctrl/Cmd + X 只有在字段可编辑、非必填且 Policy 完整允许时才清除源字段。
  • 剪贴板写入失败不会产生删除事务，审计不包含字段原文。

粘贴

  • 按 internal → HTML 表格 → 纯文本顺序选择可声明的输入表示。
  • 全部候选都失败时，`candidateFormat` 标记每条无值诊断的来源格式。
  • 输入尺寸、单元格数量、公式前缀和目标代际都会在提交前检查。
  • 成功粘贴只产生一个可撤销事务；取消或失败保持 Snapshot 不变。

08

Props 与 Outputs

组件门面只接收纯前端输入，宿主通过 outputs 获取结果并回显受控状态。

const component = createBomEditorComponent({
  schema,
  document: snapshot,
  columns: [
    { columnId: 'materialCode', fieldName: 'materialCode', fieldPath: ['materialCode'], label: '物料编码', width: 140, editable: true, frozen: 'start' },
    { columnId: 'quantity', fieldName: 'quantity', fieldPath: ['specification', 'quantity'], label: '数量', width: 116, editable: true, frozen: false },
  ],
  initialView: {
    rowHeight: 30,
    rowHeights: [{ occurrenceId: 'occ-0002', rowHeight: 48 }],
    columns: [
      { columnId: 'materialCode', width: 140, frozen: 'start', visible: true },
      { columnId: 'quantity', width: 116, frozen: false, visible: true },
    ],
    expandedIds: ['occ-0001'],
    selection: {
      activeCell: { occurrenceId: 'occ-0001', columnId: 'materialCode' },
      range: null,
    },
    scrollLeft: 0,
    scrollTop: 0,
  },
  editNavigation: { enter: 'down', tab: 'next-editable' },
  outputs: {
    onDocumentChange: ({ snapshot, commit, patch }) => {
      renderRevision(commit.revision);
      persist(snapshot);
    },
    onViewChange: (event) => {
      saveView({ columns: event.view.columns, rowHeights: event.view.rowHeights });
    },
    onError: (event) => showError(event.error.code),
  },
});
受控边界schema、document、列定义和 view 状态由宿主持有；剪贴板、导出、粘贴授权、插件和日志等函数型配置必须通过 TypeScript Props 传入。组件不会接受 DataSource、持久化或远程订阅对象。部分 Snapshot 的跨未加载结构移动会通过结构请求输出给宿主。

导出与展示

  • exportData() 必须明确 currentView、completeData 或 roundTripTemplate，并通过宿主 exportPolicy 授权。
  • configurePresentation() 只改变 locale、RTL、标签和主题；高对比由完整主题 token 提供。
  • 浏览器缩放属于宿主容器环境，不会写入 Snapshot、revision 或组件视图状态。

多实例与销毁

  • 每个实例必须使用独立 instanceId，焦点、选区和事务不会跨实例共享。
  • unmount() 释放视图资源并允许重新 mount()；destroy() 才是最终销毁，之后不能复用实例。
  • 示例中心的“多实例焦点隔离与生命周期”会真实演练上述顺序并显示返回结果。
09

性能与边界

Demo 用于功能体验，性能结论必须来自固定环境和正式 evidence runner。

工作台能证明什么

  • 真实鼠标、键盘、原生滚动、Canvas、语义 DOM 和 Portal 是否可用。
  • 公开 API 的输入输出顺序、错误处理和 Undo/Redo 是否符合预期。
  • 移动端 390 CSS px 下控件是否保持可操作。

工作台不能证明什么

  • 不能替代 100K/正式 10K P95/P99 性能报告。
  • 不能替代 WCAG/读屏人工验收、2 小时 soak 或内存留存结论。
  • 不能将 smoke 的 unqualified 结果解释成 release qualification。
10

故障排查

先根据状态栏错误码判断是输入、权限、目标代际还是环境问题。

页面没有列头、行号或滚动条

确认使用生产构建并等待“10K 文档已就绪”；检查容器是否有稳定高度，避免把编辑器放进高度为 0 的父级。

拖动列宽或列位置没有反应

列头边界需要命中 6px 热区，列移动需要从列头文字区域开始；触摸设备不启动鼠标拖拽，使用列头右键或键盘快捷键。

粘贴被拒绝

查看状态栏错误码，重点检查目标列是否可编辑、输入是否超出限额、公式保护和 Policy 是否允许。拒绝不会改变 Snapshot。

输出事件没有到达宿主

确认组件没有 destroy，输出回调是函数，并使用当前 documentGeneration 和 revision 回显受控输入。
