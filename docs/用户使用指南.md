# BOM 编辑器用户使用指南

这份指南面向组件集成者和 Demo 使用者。可交互的完整版本由 Demo 独立帮助页提供：

[打开在线帮助页](../apps/demo/src/help.html)

## 页面入口

- `/`：真实 BOM 工作台，验证鼠标、键盘、滚动、编辑、撤销重做和响应式布局。
- `/examples.html`：公开 API 示例中心。每个示例都提供说明、输入 JSON、输出协议和代码页签。
- `/help.html`：可搜索的用户帮助页，覆盖常用操作和故障排查。
- `/acceptance.html`：自动化验收专用页面，不作为日常操作入口。

## 常用操作

1. 单击单元格选择，双击或按 `Enter`/`F2` 编辑。
2. 按 `Ctrl/Cmd + Z` 撤销，按 `Ctrl/Cmd + Y` 或 `Ctrl/Cmd + Shift + Z` 重做。
3. 拖动单元格创建矩形选区，拖动选区右下角填充柄向下复制；按住 `Alt` 开始单矩形拖拽，可按前两行数值或 ISO 时间序列继续填充。
4. 在列头或行号上打开右键菜单，执行插入、删除、隐藏、冻结、移动和展开折叠；拖动行号可移动树节点，靠近上下边缘会自动滚动。
5. 按 `Ctrl/Cmd + F` 打开查找，支持前缀、精确、模糊、正则、上一项、下一项和计数。
6. 选中列内单元格后打开“列设置”，修改显示格式、对齐和自动换行。

## 集成原则

组件通过 `document`、列定义和其他 Props 接收受控输入，通过 Outputs 输出文档提交、选择、视图、编辑、剪贴板和错误事件。宿主应使用事件中的 `documentId`、`generation` 和 `revision` 做回显校验，不应读取 renderer 内部对象。

创建期视图统一放在 `initialView`：可配置完整列几何 `columns`、默认 `rowHeight`、按稳定行 ID 保存的 `rowHeights`、`expandedIds`/`expandAll`、`query`、稳定 ID `selection` 以及 `scrollLeft`/`scrollTop`。`columns` 和 `rowHeights` 可直接采用 `onViewChange` 中的 `event.view.columns`/`event.view.rowHeights`，用于恢复列布局和变量行高；行号右键菜单可设置、自动调整或恢复默认行高，列头右键菜单可恢复默认列宽。所有这些只属于视图交互历史，不改变 Snapshot/revision。顶层列定义仍负责字段路径、编辑性、格式和宽度约束。查询路径必须指向 schema 中的字段，视口宽高由挂载容器测量；旧的顶层视图字段仅用于兼容回退。

## 失败处理

只读列、Schema 不合法、输入超限、权限拒绝或 revision 过期都会失败关闭，当前 Snapshot 不产生部分修改。先查看工作台状态栏中的错误码，再检查目标列权限、输入格式、Policy 和文档代际。

## Agent 接入

组件对自有 Agent 和第三方 Agent 使用 `bom-editor-capabilities/v1`。这是编辑器的领域协议；MCP 用来把能力目录映射为模型工具，A2A 只在多个 Agent 之间委派任务时使用。不要让 Agent 直接操作 DOM、Canvas 或内部编辑器对象。

```ts
import {
  createBomEditor,
  createBomEditorAgentCapabilityAdapter,
  createBomEditorMcpAdapter,
  createBomEditorMcpProtocolServer,
} from '@qkplm/bom-editor';

const editor = createBomEditor({ schema, columns, initialDocument: document });
const agent = createBomEditorAgentCapabilityAdapter(editor, {
  grantedPermissions: ['document:read', 'document:write', 'history:write'],
});
const mcp = createBomEditorMcpAdapter(agent);
const mcpSession = createBomEditorMcpProtocolServer(mcp, {
  serverInfo: { name: 'planning-bom-editor', version: '1.0.0' },
});

// 每个 stdio、HTTP、MessagePort 或 WebSocket 连接创建一个 mcpSession。
// 宿主把收到的已解析 JSON-RPC 消息交给 handle()，并只发送非 null 响应。
async function onMcpMessage(
  message: unknown,
  send: (response: object) => void,
): Promise<void> {
  const response = await mcpSession.handle(message);
  if (response !== null) send(response);
}

const snapshot = editor.getSnapshot();
const result = await agent.call({
  protocol: 'bom-editor-capabilities/v1',
  requestId: 'agent-request-001',
  instanceId: editor.instanceId,
  documentId: snapshot.documentId,
  documentGeneration: editor.getDiagnostics().documentGeneration,
  baseRevision: snapshot.revision,
  capability: 'executeCommand',
  origin: 'planning.agent',
  idempotencyKey: 'planning-update-001',
  input: {
    command: {
      type: 'setField',
      occurrenceId: 'row-1',
      fieldPath: ['quantity'],
      value: 12,
    },
  },
});
```

`createBomEditorMcpProtocolServer()` 支持 `initialize`、`notifications/initialized`、`ping`、`tools/list`、`tools/call`、`resources/list`、`resources/read` 与 `notifications/cancelled`；未初始化前拒绝工具和资源调用，并把取消通知传递给在飞工具的 `AbortSignal`。它不启动监听端口，也不认证客户端。每个连接必须单独创建并在连接关闭时调用 `dispose()`；宿主负责消息编解码、身份认证、来源校验、超时和审计。

所有写文档请求必须携带当前 `documentId`、`documentGeneration`、`baseRevision` 和唯一 `idempotencyKey`。revision 已过期时先读取最新 Snapshot 并重新规划，不能盲目重试；同一个幂等键只能重试相同请求。适配器默认拒绝权限，远程调用必须由宿主注入授权策略。导入导出的文件由宿主附件桥接管理，不能把 `Blob`、流或文件内容放进 Agent JSON 请求。
